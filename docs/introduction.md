# Introduction

Welcome to the official documentation for **Nimbus Analytics**, a product analytics platform that helps product teams measure, understand, and optimize user behavior across web and mobile applications.

Nimbus Analytics provides real-time event tracking, funnels, and retention analysis while remaining privacy-friendly: it is cookieless and GDPR-compliant by design. Whether you run on our cloud or self-host, you can start understanding your users, one event at a time.

## What you will find here

- **Installation** – how to set up Nimbus Analytics in your environment.
- **API Reference** – details on the Nimbus Analytics API for sending and querying events.
- **Guides** – step-by-step walkthroughs such as the quickstart guide.
