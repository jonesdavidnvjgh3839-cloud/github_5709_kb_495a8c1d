# Installation

This guide explains how to install and configure **Nimbus Analytics**.

Nimbus Analytics supports flexible deployment options:

- **Cloud**: Sign up for a hosted workspace and start sending events within minutes. No infrastructure to manage.
- **Self-hosted**: Deploy the Nimbus Analytics platform on your own infrastructure for full control over your data.

## Prerequisites

- A supported browser for the dashboard.
- An account or license key for your chosen deployment.
- For self-hosted deployments: Docker and the system requirements listed in the release notes.

## Next steps

Once installed, follow the [quickstart guide](../guides/quickstart.md) to track your first events, or see the [API reference](api-reference.md) for programmatic access.
